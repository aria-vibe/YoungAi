## 一句话进来, 文件交出去

- **读写文件** Word / Excel / PPT / PDF 直接生成, 不装任何工具
- **查网页** 火狐无头浏览, 结果带来源
- **内核沙盒** 每次动手都在 Landlock / Seatbelt 里, 没有网络, 只能写工作区
- **越界先问** 工作区以外的写、联网外送都要点头

## 云手机: 自建 vs 外采

### 自建虚拟安卓

- 一次投入, 长期零成本
- 截图和元素表不出本机
- 中文输入走剪贴板, 不装输入法

### 外采云手机服务

- 按台按月付费
- 画面经第三方中转
- 版本更新不由我们定

<!-- 对比页讲清楚为什么选自建。 -->

## 解码速度三个季度翻了一倍

- 单路贪心从 **21.7** 到 42.9 t/s
- 投机解码默认开, 采样路同步提速

| line | 单路贪心 (t/s) | 采样 + 投机 (t/s) |
|---|---|---|
| Q1 | 21.7 | 18.0 |
| Q2 | 31.7 | 28.9 |
| Q3 | 42.9 | 39.3 |

## 后训练: 料只有两种, 训练只有一条命令

- messages 或 text 两种 jsonl, 和主流训练器一致
- 选轮规则: 留出损失比第 0 步低, 且收口不少于部署态
- 训完**不自动挂**, 开关打开才挂

<!-- 强调"训完不自动挂"是用户定的规矩。 -->
