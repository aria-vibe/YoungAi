# 科研写作的结构模板

每种文体先按这里的骨架列提纲, 给用户看过再填。字数是常见期刊和申请书的量级, 用户有要求以用户的为准。

## 1. 文献综述

1. 引言(300~500 字): 这个领域解决什么问题; 为什么现在值得综述(新方法、新数据、争议); 综述的范围(时间、学科、方法)和怎么找的文献(查了哪些库、关键词、筛选标准、最后多少篇)。
2. 背景与概念(300~500 字): 核心概念的定义; 领域的发展脉络(三到五个阶段, 每段一两篇代表作)。
3. 主体, 按流派或按问题分节(每节 500~1000 字): 每节先说这一派解决什么、代表工作是谁、怎么做的、效果如何; 再说这一派的局限; 几派之间的关系用一张对比表(方法 / 代表文献 / 优点 / 局限 / 适用场景)。
4. 现状评估(300~500 字): 哪些问题已经解决得不错, 哪些仍是争议, 哪些是空白; 评价要有依据(引文献或数字)。
5. 未来方向(200~400 字): 三到五条, 每条说清为什么重要、难在哪。
6. 参考文献: 文内每一处标注都对应一条, 条目格式按用户指定。

## 2. 研究论文(IMRaD)

- 标题: 说清研究对象和主要发现, 15 个词以内, 不用"研究""探讨"这类空词开头。
- 摘要(150~300 字), 四句话: 背景与问题 / 做了什么(方法、数据) / 主要结果(带数字) / 结论和意义。摘要里不出现引用和缩写。
- 引言, 漏斗结构: 大背景 → 这个具体问题 → 已有工作做到哪(引文献) → 它们的不足 → 本文做什么、贡献是什么(两到四条, 列出来)。
- 方法: 别人能照着做的程度。数据来源和规模、预处理、模型或实验流程、评价指标、统计方法(检验、显著性水平、软件或工具)、伦理审批(涉及人或动物时)。
- 结果: 只摆事实, 不解释。每段对应一张图或表; 先说主要发现再说次要; 数字带效应量和置信区间或标准差、n。
- 讨论: 主要发现是什么 → 和已有文献比(一致的、不一致的、为什么) → 可能的机制或解释 → 局限(样本、方法、外推范围) → 意义和下一步。
- 结论: 两三句, 回答引言里提的问题, 不引入新结果。

## 3. 实验记录 / 复现记录

每次实验一节, 字段固定, 方便以后对比:

- 日期和目的: 想验证什么。
- 数据: 来源、版本、规模、划分方式。
- 设置: 方法、超参数、随机种子、环境(机器、软件版本)。
- 怎么跑: 用了哪个文件、什么参数。
- 结果: 表格, 和基线或论文报告值并排, 差值一列。
- 观察: 哪里和预期不一样, 可能的原因, 下一步改什么。

## 4. 审稿回复(Response to Reviewers)

- 开头一段: 感谢编辑和审稿人, 概括这一版改了什么(新增实验、重写了哪节), 说明正文里改动的标记方式(颜色或修订模式)。
- 每位审稿人一节, 每条意见一项, 编号对应: 先原样引用意见, 再回应。
- 回应的三种写法: 接受(改了什么、在第几页第几节, 必要时把改后的段落贴出来); 部分接受(做了哪部分、哪部分为什么没做); 不接受(礼貌但明确, 给依据: 文献、数据或逻辑)。
- 补了实验的, 结果直接在回复里给表, 正文里也放。
- 结尾: 再次感谢, 希望修改版满足要求。
- 语气: 具体、不辩解、不过度道歉; 审稿人误读时客气地指出原文位置并补充说明, 同时考虑是不是原文写得不清楚, 顺手改清楚。

## 5. 开题报告 / 基金申请书(立项依据部分)

1. 研究意义(科学意义 + 应用价值): 这个问题为什么重要, 解决了会怎样。
2. 国内外研究现状: 按第 1 节综述的写法, 但更短(1000~2000 字), 落脚到"现有工作的不足"。
3. 拟解决的科学问题(两到三条, 每条一句话说清)。
4. 研究内容: 和科学问题一一对应; 每条写清做什么、怎么做、预期得到什么。
5. 研究方案与技术路线: 一张流程图(用 render_image 画: 输入 → 各步骤 → 输出, 每步标用什么方法), 外加文字说明; 关键技术和可行性分析(前期工作、已有数据、团队条件)。
6. 创新点(两到三条, 和研究内容对应, 说清和已有工作的区别)。
7. 研究基础与条件、年度计划、经费预算(按资助机构的表格)。
8. 预期成果: 论文、专利、软件、人才培养, 要可数。

## 6. 组会汇报的页次

背景与问题(1~2 页) → 相关工作(1 页, 一张对比表) → 方法(2~3 页, 一张流程图或架构图) → 实验设置(1 页) → 结果(2~4 页, 一页一张图或表) → 分析与失败案例(1~2 页) → 下一步计划(1 页)。15 分钟 10~15 页。

## 7. 常用引用格式(文末列表)

- GB/T 7714(中文期刊常用): 作者. 题名[J]. 刊名, 年, 卷(期): 起止页. DOI. 三位以上作者写前三位加"等"; 会议论文类型标 [C], 学位论文 [D], 专著 [M], 预印本 [EB/OL] 并写访问日期和网址。
- APA 第 7 版: Author, A. A., & Author, B. B. (Year). Title of the article. Journal Name, volume(issue), pages. https://doi.org/xxx 文内标注 (Author & Author, Year)。
- IEEE: [1] A. Author, B. Author, and C. Author, "Title," Journal, vol. 1, no. 2, pp. 3–4, Month Year, doi: xxx. 文内按出现顺序编号。
- arXiv 预印本: 作者. 题名. arXiv:编号 [学科类], 年. 正式发表后换成期刊或会议版。
- 拿不准的字段(卷期页)去 Crossref 用 DOI 查, 不猜。
